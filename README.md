# 🌐 Desarrollo Web — DAM

Repositorio de la asignatura de **Desarrollo Web** del ciclo formativo de **Desarrollo de Aplicaciones Multiplataforma (DAM)**.

## 📚 Sobre la asignatura

En esta asignatura se trabajan los principales conceptos necesarios para desarrollar aplicaciones y páginas web, utilizando diferentes tecnologías y lenguajes.

## 🛠️ Tecnologías utilizadas

Durante el curso se trabajará principalmente con:

* HTML5
* CSS3
* JavaScript
* Git y GitHub
* Diseño responsive
* Flexbox
* CSS Grid
* Formularios
* DOM
* Programación web

## 🎯 Objetivos

* Aprender a crear páginas web desde cero.
* Comprender la estructura de un documento HTML.
* Aplicar estilos mediante CSS.
* Crear diseños adaptables a diferentes dispositivos.
* Añadir interactividad mediante JavaScript.
* Utilizar Git y GitHub para gestionar proyectos.
* Mejorar progresivamente las buenas prácticas de programación.
